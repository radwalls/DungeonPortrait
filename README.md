# Dungeon Portrait Prototype

Minimal first-person mobile dungeon prototype in portrait mode with randomized Wolfenstein-style tunnel progression.

## Run

Open `index.html` in a mobile browser (or desktop device emulation).

## Controls

- **Swipe up** in the gameplay area to step forward.
- **Tap enemies directly** to attack with a POV sword swing.
- **Choose left/right** when an intersection appears.
- **Reach the exit** to descend into the next, lower dungeon level.
- **Character** and **Inventory** open full-screen menus and pause gameplay.
