# Dungeon Portrait Prototype

Minimal first-person mobile dungeon prototype in portrait mode with randomized Wolfenstein-style corridor progression.

## Run

Open `index.html` in a mobile browser (or desktop device emulation).

## Controls

- **No auto-move:** movement happens only when you swipe up.
- **Swipe up** to take one forward step.
- **Tap enemies directly** to attack with a POV sword swing.
- **Choose left/right** when a Y-fork appears.
- **Reach the exit stair** to descend into the next lower dungeon level.
- **Character** and **Inventory** open full-screen menus and pause gameplay.
