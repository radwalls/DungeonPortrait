# Dungeon Portrait Prototype

Minimal first-person mobile dungeon prototype in portrait mode.

## Run

Open `index.html` in a mobile browser (or desktop device emulation).

## Controls

- **Automatic forward movement** starts by default.
- **Swipe up** in gameplay area for a forward burst or to resume walking.
- **Swipe down** to stop walking.
- **Tap enemies directly** to swing the POV sword and attack.
- **Y-fork events** pause movement and let you choose **Left Branch** or **Right Branch**.
- **Character** and **Inventory** open full-screen menus and pause gameplay.
