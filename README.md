# Dungeon Portrait Prototype

Minimal first-person mobile dungeon tunnel prototype in portrait mode.

## Run

Open `index.html` in a mobile browser (or desktop device emulation).

## Controls

- Character walks forward automatically.
- Swipe up to surge ahead.
- Swipe down to halt movement.
- Tap enemies directly to attack with a POV sword swing.
- At Y-forks, tap left or right path wedges to choose direction.
- Character and Inventory open full-screen pause menus.
