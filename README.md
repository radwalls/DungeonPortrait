# Dungeon Portrait Prototype

Minimal first-person mobile dungeon prototype in portrait mode with atmospheric tunnel traversal.

## Run

Open `index.html` in a mobile browser (or desktop device emulation).

## Controls

- **Automatic forward movement** is active unless halted.
- **Swipe up** in the gameplay area for a short forward surge.
- **Swipe down** to stop and hold position.
- **Tap enemies directly** to attack with a POV sword swing.
- **Choose left/right** when a Y-fork appears in the tunnel.
- **Character** and **Inventory** open full-screen menus and pause gameplay.
