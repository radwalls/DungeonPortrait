# Dungeon Portrait

A first-person-feel medieval dungeon crawler designed for **portrait mobile play**.

## Core loop

- Swipe up (or tap **Descend**) to push deeper.
- Face procedural events: enemies, traps, or treasure corridors.
- In combat, tap **Tap to Strike** with timing for bonus damage.
- After victories, choose between recovery, stamina, or rapid descent.
- The deeper you go, the harder enemies hit.
- Across runs, best depth unlocks stronger starting gear.

## Run locally

Open `index.html` in any modern mobile or desktop browser.
