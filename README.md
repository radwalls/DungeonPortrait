# Dungeon Portrait Prototype

Portrait-mode first-person dungeon prototype with randomized Wolfenstein-style corridor progression.

## Run

Open `index.html` in a mobile browser (or desktop device emulation).

## Controls

- **No auto movement**: the character stands still until input.
- **Swipe up** to advance forward in short movement bursts.
- **Swipe down** to stop immediately.
- **Tap enemies directly** to attack with the POV sword.
- **Choose left/right** when randomized Y-forks appear.
- Reach the **exit stair** to descend into a new lower level.
- **Character** and **Inventory** open full-screen menus and pause gameplay.
