# Dungeon Portrait Prototype

Portrait-mode first-person dungeon prototype with randomized Wolfenstein-style floor layouts.

## Run

Open `index.html` in a mobile browser (or desktop device emulation).

## Controls

- **Swipe up** to step forward one tile.
- **Swipe left/right** to turn in place.
- **Tap visible enemies** to attack with the POV sword.
- **Find the glowing exit** to descend to the next lower dungeon level.
- **Character** and **Inventory** open full-screen menus and pause gameplay.
