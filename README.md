# Dungeon Portrait Prototype

Minimal first-person mobile dungeon prototype in portrait mode.

## Run

Open `index.html` in a mobile browser (or desktop device emulation).

## Controls

- Automatic forward movement is active by default.
- Swipe up for a forward surge (also resumes movement if halted).
- Swipe down to halt movement.
- Tap enemies directly to attack with a POV sword swing.
- Choose Left/Right when a Y-fork appears in the tunnel.
- Character and Inventory open full-screen pause menus.
